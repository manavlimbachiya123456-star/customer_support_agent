# Cancellation Policy

## When an order can be cancelled
An order can be cancelled only before it ships, while its status is PLACED. Every cancellation must be approved by a support agent.

## After shipping
Once an order has shipped it cannot be cancelled. If the order has been delivered the customer can use the return process. If it is delayed, the customer can ask for a refund when it is more than 3 days overdue.

## Already cancelled orders
A cancelled order cannot be cancelled again. Refunds for cancelled orders are handled automatically with the original payment and no new refund request is needed.
