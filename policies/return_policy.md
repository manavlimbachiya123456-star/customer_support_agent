# Return Policy

## Return window
Items can be returned within 30 days of delivery. The item should be unused and in its original packaging.

## How returns work
The customer asks for a return, a support agent approves it, and a pickup is arranged. A return reference number (RMA) is created when the return is approved.

## Refunds after a return
After the returned item reaches our warehouse and is checked, the refund is processed by the returns team. The customer does not need to make a separate refund request.

## Items that cannot be returned
Orders that were cancelled, refunded or already returned cannot be returned again. Orders still waiting for delivery cannot be returned.
